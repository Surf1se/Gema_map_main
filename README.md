# Gema Map

Общая карта с регистрацией и обновлением геопозиций в реальном времени. Пользователь включает передачу своей позиции, и все вошедшие участники видят его точку. Отдельные приглашения и подтверждения дружбы не нужны.

## Запуск

Нужен **Node.js 24 или новее** (используется встроенный SQLite). Из папки проекта:

```sh
npm ci
npm start
```

Локально откройте `http://localhost:3000`. Для автоматического перезапуска сервера при разработке: `npm run dev`.

Создайте два аккаунта в разных браузерах или обычном и приватном окнах. В каждом нажмите «Включить геопозицию» и разрешите её в браузере. Обе точки появятся на общей карте. Кнопка «Остановить передачу» скрывает свою точку. Собственная точка выделена синим; нажатие на участника приближает его положение.

## Доступ с телефонов и других устройств

Для общего онлайн-доступа нужен **один постоянно работающий сервер Node.js с HTTPS** и постоянным диском. Все пользователи должны открывать один и тот же адрес. Локальный запуск сам по себе не публикует приложение в интернете. Геопозиция по обычному HTTP на сетевом IP недоступна: исключение браузеров — localhost на том же устройстве.

Настройки сервера:

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт HTTP-сервера за HTTPS-прокси |
| `HOST` | `0.0.0.0` | Интерфейс прослушивания |
| `NODE_ENV` | не задано | Для публичного HTTPS-развёртывания задайте `production`: cookie станут Secure |

SQLite создаётся автоматически в `.data/gema.sqlite` относительно папки проекта. Сохраняйте всю папку `.data` на постоянном диске и делайте резервные копии; она содержит аккаунты и хешированные сессии. Не публикуйте её и не добавляйте в Git. В первой версии используется **один процесс сервера**: координаты и подключения находятся в памяти. Несколько экземпляров требуют общей системы обмена сообщениями и хранилища.

На reverse proxy отключите буферизацию для `/api/events` и разрешите длительные SSE-соединения. Сервер отправляет heartbeat каждые 10 секунд. Статические файлы Leaflet включены в npm-зависимости; для подложки карты браузерам нужен HTTPS-доступ к `a.tile.openstreetmap.org`, `b.tile.openstreetmap.org`, `c.tile.openstreetmap.org`. Соблюдайте [политику использования стандартных тайлов OSM](https://operations.osmfoundation.org/policies/tiles/); для большой нагрузки выберите подходящего поставщика тайлов.

## Передача координат

- При регистрации явно указано: имя и точные координаты видны **всем зарегистрированным участникам**, пока включена передача. После входа она включается отдельной кнопкой и требует разрешения браузера.
- Карта доступна вошедшему пользователю и без передачи собственной позиции.
- Координаты получаются через `watchPosition`, отправляются сразу при изменении и повторно каждые 15 секунд, пока показания свежие. Точность зависит от устройства; приложение её показывает.
- После остановки или выхода точка удаляется. При закрытии страницы отправляется запрос остановки; если он не дошёл, точка исчезнет не позднее чем через 90 секунд после последнего измерения (плюс до 10 секунд на уведомление подключённых карт).
- Координаты не записываются в SQLite. Истории перемещений нет; после перезапуска сервера карта пуста до новых обновлений.
- Фоновое отслеживание и работа при закрытой вкладке не поддерживаются. Мобильная ОС может приостанавливать геолокацию и сеть. После перезагрузки страницы передача включается снова вручную.

## Проверки

```sh
npm test
npm run test:browser
```

Первый набор проверяет регистрацию, согласие, аутентификацию, передачу координат между двумя участниками по SSE, остановку передачи, валидацию координат, защиту от межсайтовых запросов, выход, сохранность аккаунтов после перезапуска и ограничение попыток входа.

Браузерный тест использует Playwright и Chromium: два независимых аккаунта, изменение координат, удаление точек, мобильный экран, повторный вход и отказ в доступе к геопозиции. Если `/usr/bin/chromium` отсутствует, установите браузер командой `npx playwright install chromium` либо задайте `CHROMIUM_PATH` на существующий Chromium. Для Linux могут потребоваться системные библиотеки браузера. Координаты в тесте имитируются; реальную точность GPS нужно проверять на устройстве.

## Объём первой версии

Есть регистрация по email и паролю, вход, общая карта, список участников, свои и чужие точки, остановка передачи и выход. Пароли хешируются scrypt с уникальной солью; сессии используют HttpOnly/SameSite cookie. Подтверждение email, восстановление пароля, закрытые группы, управление аккаунтами и промышленная защита от злоупотреблений пока не реализованы. Сервис не опубликован автоматически: для этого нужно выбрать хостинг и HTTPS-домен.
