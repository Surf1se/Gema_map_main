# Gema

Веб-платформа с общей картой и счётчиком пользователей онлайн. Карта остаётся доступной для будущих возможностей. Приложение не запрашивает геопозицию, не получает координаты пользователей и не размещает их на карте.

## Запуск

Нужен **Node.js 24 или новее** (используется встроенный SQLite). Из папки проекта:

```sh
npm ci
npm start
```

Локально откройте `http://localhost:3000`. Для автоматического перезапуска сервера при разработке: `npm run dev`.

Зарегистрируйтесь или войдите. В боковой панели показано только количество пользователей онлайн. Каждый аккаунт учитывается один раз, даже если у него открыто несколько вкладок. После закрытия всех вкладок, выхода или истечения сессии счётчик уменьшается.

## Развёртывание

Для общего доступа нужен постоянно работающий сервер Node.js с HTTPS и постоянным диском. Все пользователи должны открывать один и тот же адрес.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт сервера |
| `HOST` | `0.0.0.0` | Интерфейс прослушивания |
| `NODE_ENV` | не задано | Для публичного HTTPS задайте `production`: cookie станут Secure |

SQLite создаётся в `.data/gema.sqlite`. Сохраняйте `.data` на постоянном диске и делайте резервные копии: там находятся аккаунты и хешированные сессии. Онлайн-соединения хранятся только в памяти сервера; для нескольких экземпляров приложения понадобится общий механизм учёта присутствия.

На обратном прокси отключите буферизацию для `/api/events` и разрешите долгие SSE-соединения. Сервер отправляет heartbeat каждые 10 секунд. Для подложки карты нужен HTTPS-доступ к `a.tile.openstreetmap.org`, `b.tile.openstreetmap.org` и `c.tile.openstreetmap.org`. Соблюдайте [политику использования стандартных тайлов OSM](https://operations.osmfoundation.org/policies/tiles/).

## Онлайн и приватность

Счётчик обновляется через SSE и сообщает браузеру только число уникальных аккаунтов с открытым соединением. Имена, email, идентификаторы пользователей и координаты в событиях не передаются. Существующие аккаунты сохраняются; согласие на передачу геопозиции при регистрации больше не требуется.

Карта не определяет местоположение устройства. Старые API-адреса `/api/location` и `/api/location/stop` удалены.

## Проверки

```sh
npm test
npm run test:browser
```

Браузерный тест использует Playwright и Chromium. Если браузер Playwright не установлен, выполните `npx playwright install chromium` либо задайте `CHROMIUM_PATH` на существующий Chromium. На Windows при запрете запуска `npm.ps1` можно выполнить `node --test test/api.test.js` и `node --test test/browser.test.js`.
