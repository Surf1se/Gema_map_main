# Gema

Веб-платформа с картой предупреждений и счётчиком пользователей онлайн. Приложение не запрашивает геопозицию пользователей. Красные круги показывают приблизительное положение населённых пунктов, о которых канал [«Радар Москва»](https://t.me/radar_moscoww) прямо написал об опасности по БПЛА или ракетной опасности. Круги не показывают фактическую зону угрозы, а сообщения канала не проверяются приложением по другим источникам.

## Запуск

Нужен **Node.js 24 или новее** (используется встроенный SQLite). Из папки проекта:

```sh
npm ci
npm start
```

Локально откройте `http://localhost:3000`. Для автоматического перезапуска сервера при разработке: `npm run dev`.

Без настройки Telegram карта запускается, но круги из канала не появляются.

Зарегистрируйтесь или войдите. В боковой панели показано только количество пользователей онлайн. Каждый аккаунт учитывается один раз, даже если у него открыто несколько вкладок. После закрытия всех вкладок, выхода или истечения сессии счётчик уменьшается.

## Подключение Telegram

1. Создайте локальный `.env` по образцу [.env.example](./.env.example) и впишите `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` из [API development tools](https://my.telegram.org). `.env` и `.data` исключены из Git.
2. Выполните `npm run telegram:login` (на Windows в PowerShell можно `npm.cmd run telegram:login`). Введите номер, код входа и пароль двухэтапной проверки, если Telegram его запросит. Сессия сохранится только в `.data/telegram.session`; не отправляйте этот файл, коды или `api_hash` другим людям.
3. Запустите `npm start`. Сервер прочитает публикации канала за текущий цикл и будет получать новые и отредактированные сообщения через ваш аккаунт. Для непрерывной работы процесс сервера должен оставаться запущенным.

Сообщения об опасности без распознанного населённого пункта, прогнозы, общие новости и сообщения о сбитии не создают круг. «Отбой» для населённого пункта снимает его круг; «отбой» без населённого пункта снимает все круги. Оставшиеся предупреждения удаляются ежедневно в **08:00 по Москве**. Несколько тревожных постов об одном месте отображаются одним кругом. Если название неоднозначно или отсутствует в справочнике, круг может не появиться.

Для поиска населённых пунктов используется локальный [справочник GeoNames](./data/ru-places.json), созданный из [набора RU](https://download.geonames.org/export/dump/RU.zip), [CC BY 4.0](https://www.geonames.org/). Файл можно обновить командой `node scripts/build-places.js` после загрузки и распаковки `RU.zip` в `.data/geonames/`. Радиус круга условный: 3–12 км в зависимости от размера населённого пункта.

## Развёртывание

Для общего доступа нужен постоянно работающий сервер Node.js с HTTPS и постоянным диском. Все пользователи должны открывать один и тот же адрес.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт сервера |
| `HOST` | `0.0.0.0` | Интерфейс прослушивания |
| `NODE_ENV` | не задано | Для публичного HTTPS задайте `production`: cookie станут Secure |

SQLite создаётся в `.data/gema.sqlite`. Сохраняйте `.data` на постоянном диске и делайте резервные копии: там находятся аккаунты и хешированные сессии. Онлайн-соединения хранятся только в памяти сервера; для нескольких экземпляров приложения понадобится общий механизм учёта присутствия.
В `.data` также хранится сессия Telegram, дающая доступ к вашему аккаунту, поэтому ограничьте доступ к этой папке. Предупреждения сохраняются в SQLite до отбоя или следующего сброса в 08:00.

На обратном прокси отключите буферизацию для `/api/events` и разрешите долгие SSE-соединения. Сервер отправляет heartbeat каждые 10 секунд. Для подложки карты нужен HTTPS-доступ к `a.tile.openstreetmap.org`, `b.tile.openstreetmap.org` и `c.tile.openstreetmap.org`. Соблюдайте [политику использования стандартных тайлов OSM](https://operations.osmfoundation.org/policies/tiles/).

## Онлайн и приватность

Счётчик обновляется через SSE и сообщает браузеру только число уникальных аккаунтов с открытым соединением. Имена, email и идентификаторы пользователей в событиях не передаются. События предупреждений содержат название населённого пункта, примерные координаты его центра и ID исходного поста. Существующие аккаунты сохраняются.

Карта не определяет местоположение устройства. Старые API-адреса `/api/location` и `/api/location/stop` удалены.

## Проверки

```sh
npm test
npm run test:browser
```

Браузерный тест использует Playwright и Chromium. Если браузер Playwright не установлен, выполните `npx playwright install chromium` либо задайте `CHROMIUM_PATH` на существующий Chromium. На Windows при запрете запуска `npm.ps1` можно выполнить `node --test test/api.test.js test/alerts.test.js` и `node --test test/browser.test.js`.
