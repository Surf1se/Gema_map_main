# Gema

Веб-платформа с картой предупреждений и счётчиком пользователей онлайн. Приложение не запрашивает геопозицию пользователей. Контуры районов и регионов и круглые маркеры населённых пунктов показывают места, о которых каналы [«Радар Москва»](https://t.me/radar_moscoww) и [«Радар по всей России»](https://t.me/radarrussiia) прямо написали об опасности. При отсутствии контура района или региона показывается маленький ромб в центре территории. Закрашенная область не показывает фактическую зону угрозы, а сообщения каналов не проверяются приложением по другим источникам.

## Запуск

Нужен **Node.js 24 или новее** (используется встроенный SQLite). Из папки проекта:

```sh
npm ci
npm start
```

Локально откройте `http://localhost:3000`. Для автоматического перезапуска сервера при разработке: `npm run dev`.

Без настройки Telegram карта запускается, но предупреждения из каналов не появляются.

Зарегистрируйтесь или войдите. В боковой панели показано только количество пользователей онлайн. Каждый аккаунт учитывается один раз, даже если у него открыто несколько вкладок. После закрытия всех вкладок, выхода или истечения сессии счётчик уменьшается.

## Карта Яндекса

Подложка Яндекса подключается через [Yandex Maps Tiles API](https://yandex.ru/maps-api/products/tiles-api). Создайте ключ именно для **Tiles API** в [кабинете разработчика](https://developer.tech.yandex.ru/), затем добавьте в локальный `.env` строку `YANDEX_TILES_API_KEY=ваш_ключ` и перезапустите сервер. Ключ не нужно отправлять в чат или добавлять в Git. Для локального просмотра разрешите `localhost` в ограничениях ключа; при публикации настройте ограничение для домена сайта. Ключ передаётся браузеру для прямой загрузки тайлов, поэтому ограничения ключа обязательны. Без ключа и при ошибке загрузки тайлов показывается OpenStreetMap.

Карта Яндекса показывает подложку и названия, а красные контуры по-прежнему берутся из OpenStreetMap через Nominatim. Tiles API возвращает изображения карты, а не геометрию границ территорий. Для совпадения подложки с контурами используется проекция `web_mercator`. На карте размещён обязательный кликабельный логотип Яндекса. Для бесплатной версии Tiles API указан предел 30 запросов в секунду.

## Подключение Telegram

1. Создайте локальный `.env` по образцу [.env.example](./.env.example) и впишите `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` из [API development tools](https://my.telegram.org). `.env` и `.data` исключены из Git.
2. Выполните `npm run telegram:login` (на Windows в PowerShell можно `npm.cmd run telegram:login`). Введите номер в международном формате с `+`, затем код входа и пароль двухэтапной проверки, если Telegram его запросит. Способ доставки кода покажет команда: чаще всего проверьте чат с подтверждённым аккаунтом «Telegram» в уже открытом приложении, а не SMS и не чат «Verification Codes». Сессия сохранится только в `.data/telegram.session`; не отправляйте этот файл, коды или `api_hash` другим людям.
   Если код не приходит, выполните `npm.cmd run telegram:login:qr` и отсканируйте QR-код в Telegram на телефоне через «Настройки → Устройства → Подключить устройство». Подтвердите вход на телефоне. QR-код даёт доступ к аккаунту, поэтому не показывайте его другим людям и не присылайте скриншот.
   Соединение с Telegram использует защищённый WebSocket. Если сеть закрывает соединение с Telegram, проверьте доступ к `venus.web.telegram.org` по HTTPS из этого компьютера.
3. Запустите `npm start`. Сервер прочитает публикации обоих каналов за текущий цикл и будет получать новые и отредактированные сообщения через ваш аккаунт. Для непрерывной работы процесс сервера должен оставаться запущенным. Надпись «Каналы подключены» появляется, когда доступны оба канала; при ошибке одного из них проверьте терминал.

Предупреждение для населённого пункта, района или региона (области, края, республики) создаёт отдельную отметку. Если пост называет и населённый пункт, и регион, регион служит контекстом; если названы район и регион, показывается район. Распознаются «опасность» и «опастность», «рокетная опастность», «угроза», «сбитие БПЛА», «массовые фиксации», «фиксация/фиксации БПЛА», «фиксация группы БПЛА», «фиксация реактивной цели», «работа ПВО по БПЛА», «внимание по БПЛА», предупреждения о возможном массовом налёте или атаке БПЛА и фразы «зафиксировали в [место]». Пост создаёт или обновляет отметку только для распознанного места. Общие сводки вроде «за ночь сбито …» без такого сообщения и прогноза для конкретного места не создают отметку. «Отбой» для населённого пункта или района снимает предупреждения этого канала для него; «отбой» по региону снимает все предупреждения этого канала в регионе; «отбой» без места снимает все предупреждения этого канала. Подтверждённый отбой отображается зелёным 5 минут, если для места больше нет активной опасности. Предупреждения другого канала остаются активными. Без новых сообщений отметки опасности исчезают через 60 минут после последнего сообщения по соответствующему месту; новое сообщение начинает отсчёт заново. Несколько тревожных постов об одном месте отображаются одной отметкой. Если название района неоднозначно и регион не указан или название отсутствует в справочнике, предупреждение может не появиться.

Для поиска используются локальные [справочник населённых пунктов](./data/ru-places.json), [справочник регионов](./data/ru-regions.json) и [справочник административных территорий](./data/ru-admins.json), созданные из российского [набора GeoNames RU](https://download.geonames.org/export/dump/RU.zip), [CC BY 4.0](https://www.geonames.org/). В них только данные России, включая города, посёлки и деревни. Файлы можно обновить командой `node scripts/build-places.js` после загрузки и распаковки `RU.zip` в `.data/geonames/`.

Регионы и районы отображаются полупрозрачным красным с серой обводкой; через 30 минут без обновления заливка становится серой, а через 60 минут исчезает. Если точный контур не найден, статус показывает маленький ромб вместо большой условной окружности. Города, посёлки, деревни и другие населённые пункты показываются ярко-красными круглыми маркерами поверх этих территорий; они исчезают через 60 минут без обновления. При наведении на маркер видно время исходной публикации сообщения по Москве; правка сообщения его не меняет. Если в сообщении явно указано «в направлении» и распознаны один начальный населённый пункт и одна цель, рядом с начальным пунктом появляется анимированный значок стрелки с дроном. Он показывает только заявленное направление, а не текущее местоположение БПЛА. Стрелка исчезает через 45 минут после сообщения о направлении; новое такое сообщение запускает отсчёт заново. После подтверждённого отбоя отметка становится зелёной на 5 минут, затем исчезает; стрелка убирается сразу. При появлении новой опасности во время просмотра карты справа сверху показывается уведомление: его можно закрыть крестиком, иначе оно исчезнет через 2 минуты. Уже активные территории при открытии страницы повторно не уведомляют.

Контур района или региона запрашивается сервером через [Nominatim OpenStreetMap](https://nominatim.org/release-docs/latest/api/Search/) при первом предупреждении для этого места. Использование публичного сервиса регулируется [его политикой](https://operations.osmfoundation.org/policies/nominatim/): приложение отправляет запросы последовательно с интервалом более секунды, указывает идентификатор приложения и сохраняет найденные и отсутствующие контуры в SQLite. Если сервис недоступен или возвращает точку вместо границы, остаётся маленький ромб в центре территории. При развёртывании с большой нагрузкой понадобится собственный источник контуров; публичный Nominatim нельзя использовать как неограниченный геокодер.

## Развёртывание

Для общего доступа нужен постоянно работающий сервер Node.js с HTTPS и постоянным диском. Все пользователи должны открывать один и тот же адрес.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт сервера |
| `HOST` | `0.0.0.0` | Интерфейс прослушивания |
| `NODE_ENV` | не задано | Для публичного HTTPS задайте `production`: cookie станут Secure |

SQLite создаётся в `.data/gema.sqlite`. Сохраняйте `.data` на постоянном диске и делайте резервные копии: там находятся аккаунты и хешированные сессии. Онлайн-соединения хранятся только в памяти сервера; для нескольких экземпляров приложения понадобится общий механизм учёта присутствия.
В `.data` также хранится сессия Telegram, дающая доступ к вашему аккаунту, поэтому ограничьте доступ к этой папке. Предупреждения сохраняются в SQLite до отбоя или истечения 60 минут без обновления.

На обратном прокси отключите буферизацию для `/api/events` и разрешите долгие SSE-соединения. Сервер отправляет heartbeat каждые 10 секунд. Для подложки Яндекса нужен HTTPS-доступ к `tiles.api-maps.yandex.ru`; для запасной подложки — к `a.tile.openstreetmap.org`, `b.tile.openstreetmap.org` и `c.tile.openstreetmap.org`. Соблюдайте [политику использования стандартных тайлов OSM](https://operations.osmfoundation.org/policies/tiles/).

## Онлайн и приватность

Счётчик обновляется через SSE и сообщает браузеру только число уникальных аккаунтов с открытым соединением. Имена, email и идентификаторы пользователей в событиях не передаются. События предупреждений содержат название населённого пункта, примерные координаты его центра и ID исходного поста. Существующие аккаунты сохраняются.

Карта не определяет местоположение устройства. Старые API-адреса `/api/location` и `/api/location/stop` удалены.

## Проверки

```sh
npm test
npm run test:browser
```

Браузерный тест использует Playwright и Chromium. Если браузер Playwright не установлен, выполните `npx playwright install chromium` либо задайте `CHROMIUM_PATH` на существующий Chromium. На Windows при запрете запуска `npm.ps1` можно выполнить `node --test test/api.test.js test/alerts.test.js` и `node --test test/browser.test.js`.
